# نظام إدارة العيادة

برنامج عيادة يُباع كنسخ، بنفس نظام برنامج المتجر: لكل عيادة حساباتها وبياناتها واشتراكها،
الدخول باسم مستخدم وكلمة مرور، ولوحة مزود لإدارة الاشتراكات والحسابات والأجهزة.

## الصفحات

| الصفحة | لمن |
|---|---|
| `index.html` | صفحة الدخول (+ «جرّب البرنامج بدون حساب») — هذا الرابط الذي ترسله للعيادات |
| `app.html` | البرنامج نفسه بعد الدخول |
| `expired.html` | تظهر عند انتهاء الاشتراك أو إيقاف العيادة (مع تنزيل نسخة من البيانات) |
| `terms.html` | شروط الاستخدام |
| `provider.html` | **لوحة المزود** (لك فقط) |

## الملفات

| الملف | الوظيفة |
|---|---|
| `design.css` / `glass.css` / `theme.js` | الهوية والثيمات (فاتح، داكن، زجاج) والحركة — نفس المتجر |
| `cloud.js` | الدخول، حماية الصفحات، الاشتراك، الأجهزة، والمزامنة مع Supabase |
| `core.js` `views.js` `patient.js` `finance.js` `extras.js` | أقسام العيادة: اليوم، المواعيد، المرضى، الكشف والوصفات، الحسابات، المخزون، التقارير |
| `admin.js` | الإعدادات (حسابي، المظهر، التطبيق) وصفحة «المستخدمون والأجهزة» للطبيب |
| `demo.js` | بيانات العيادة التجريبية |
| `provider.js` | منطق لوحة المزود |
| `pwa.js` `sw.js` `manifest.webmanifest` `version.json` `icons/` | التثبيت كتطبيق، الفتح بدون إنترنت، إشعار «يتوفر تحديث» |
| `supabase/clinic.sql` | الجداول وقواعد الحماية (RLS) والأجهزة |
| `supabase/functions/clinic-admin` | دالة لوحة المزود |
| `supabase/functions/clinic-team` | دالة الطبيب لإدارة حسابات عيادته |

## التشغيل (مرة واحدة)

للعيادات مشروع Supabase خاص بها (`yukyibwkxwkssirhdhfg`)، منفصل تمامًا عن مشروع المتجر: حسابات وبيانات وحساب مزود مستقلة.

1. **قاعدة البيانات:** Supabase ← SQL Editor ← الصق محتوى `supabase/clinic.sql` كاملًا ← Run.
   (إذا شغّلته سابقًا شغّله مرة ثانية؛ يضيف جداول الأجهزة ولا يمسح شيئًا.)
2. **الدالتان:** Supabase ← Edge Functions ← دالة باسم `clinic-admin` من `supabase/functions/clinic-admin/index.ts`،
   ودالة باسم `clinic-team` من `supabase/functions/clinic-team/index.ts`. أو من الطرفية:
   ```bash
   supabase functions deploy clinic-admin --project-ref yukyibwkxwkssirhdhfg
   ```
   ```bash
   supabase functions deploy clinic-team --project-ref yukyibwkxwkssirhdhfg
   ```
3. **حساب المزود:** Authentication ← Users ← Add user (بريدك وكلمة مرور)، ثم شغّل السطر الأخير في `clinic.sql` ببريدك.
4. **المفتاح العام:** `key` في أعلى `cloud.js` = Publishable key من Project Settings ← API Keys.
5. **رقمك:** `support` في أعلى `cloud.js` (يظهر في صفحة الدخول وعند انتهاء الاشتراك وفي زر الواتساب بالتجربة).

## بيع نسخة جديدة

1. افتح `provider.html` ← «+ عيادة جديدة»: اسم العيادة والطبيب، اسم مستخدم وكلمة مرور للطبيب، الخطة، السعر، حد الأجهزة.
2. تظهر رسالة جاهزة بالرابط وبيانات الدخول: «نسخ الرسالة» أو «إرسال بالواتساب».
3. الطبيب يضيف السكرتير بنفسه من «المستخدمون والأجهزة»، أو أنت من «إدارة» ← الحسابات.

## الاشتراك والصلاحيات

- قبل الانتهاء بـ 7 أيام يظهر تنبيه للطبيب. بعد الانتهاء مهلة 3 أيام بتنبيه للجميع، ثم تتحول العيادة لصفحة «انتهى الاشتراك»
  (البيانات لا تُحذف، ويستطيع تنزيل نسخة منها) حتى تجدّد من اللوحة. «الإيقاف» من اللوحة له نفس الأثر فورًا.
- **الطبيب:** كل شيء، ويدير الحسابات والأجهزة. **السكرتير:** لا يرى التقارير ولا «المستخدمون والأجهزة» ولا إعدادات العيادة.
- **حد الأجهزة** (اختياري): السكرتير لا يدخل من جهاز جديد بعد الحد؛ الطبيب يوقف جهازًا قديمًا أو تزيد الحد من اللوحة.

## تحديث البرنامج لاحقًا

ارفع الرقم `BUILD` في `pwa.js` ونفس الرقم في `version.json` (وفي `?v=` داخل الصفحات)، فيظهر للعيادات زر «تحديث الآن».

## ملاحظات

- المتجر والعيادة على نفس الموقع، ولكل منهما جلسة دخول منفصلة، فالدخول لأحدهما لا يخرجك من الآخر.
- كل جهاز يحتفظ بنسخة للفتح السريع وللاطلاع بدون إنترنت؛ **الحفظ يحتاج إنترنت**. تسجيل الخروج يمسح النسخة من الجهاز.
- من كانت بياناته على جهازه في النسخة القديمة، يظهر له بعد أول دخول عرض لنقلها إلى حساب عيادته.
