# نظام إدارة العيادة

برنامج عيادة يُباع كنسخ: لكل عيادة حساباتها وبياناتها واشتراكها، والدخول باسم مستخدم وكلمة مرور.
نفس نظام المتجر: Supabase + لوحة مزود لإدارة الاشتراكات.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` + `*.js` | البرنامج نفسه (يفتح بصفحة تسجيل الدخول) |
| `cloud.js` | تسجيل الدخول، المزامنة مع Supabase، الاشتراك، «حسابي» |
| `provider.html` | لوحة المزود: إنشاء العيادات وحساباتها، التجديد، الإيقاف، النسخ الاحتياطي |
| `supabase/clinic.sql` | الجداول وقواعد الحماية (RLS) |
| `supabase/functions/clinic-admin` | دالة الخادم التي تستخدمها لوحة المزود |

## التشغيل لأول مرة (مرة واحدة)

البرنامج مضبوط على نفس مشروع Supabase الخاص بالمتجر، وجداوله كلها تبدأ بـ `clinic` فلا تختلط بجداول المتجر.

1. **قاعدة البيانات:** Supabase ← SQL Editor ← الصق محتوى `supabase/clinic.sql` ← Run.
2. **حساب المزود:** إذا كان حسابك مزودًا في المتجر فهو مزود هنا أيضًا ولا تحتاج شيئًا.
   وإلا شغّل السطر الأخير في `clinic.sql` بعد وضع بريدك.
3. **دالة الخادم:** من مجلد المشروع:
   ```bash
   supabase functions deploy clinic-admin --project-ref pxxgydllfustqkpkfiqn
   ```
4. **رقمك للتواصل:** غيّر `support` في أعلى `cloud.js` (يظهر في صفحة الدخول وعند انتهاء الاشتراك).
5. انشر المجلد على GitHub Pages كالمعتاد.

## بيع نسخة جديدة

1. افتح `provider.html` وادخل ببريد المزود.
2. «+ عيادة جديدة»: اسم العيادة، الطبيب، اسم مستخدم وكلمة مرور للطبيب، الخطة وتاريخ الانتهاء والسعر.
3. أرسل للطبيب رابط البرنامج واسم المستخدم وكلمة المرور.
4. من «الحسابات» تضيف حساب سكرتير، أو تغيّر كلمة مرور، أو تعطّل حسابًا.

## الصلاحيات والاشتراك

- **الطبيب (مدير):** كل شيء.
- **السكرتير:** لا يرى التقارير والإعدادات، ولا يستطيع تعديل إعدادات العيادة (ممنوع في قاعدة البيانات أيضًا).
- قبل انتهاء الاشتراك بـ 7 أيام يظهر تنبيه للطبيب. بعد الانتهاء مهلة 3 أيام، ثم يصبح البرنامج **للاطلاع فقط**
  (البيانات تبقى ظاهرة لكن لا إضافة ولا تعديل) حتى تجدّد من لوحة المزود. «الإيقاف» من اللوحة له نفس الأثر فورًا.
- الخطة «دائمي» لا تنتهي.

## ملاحظات

- البيانات تُحفظ في حساب العيادة وتظهر على كل أجهزتها (تتحدث تلقائيًا خلال ثوانٍ).
- يحتفظ كل جهاز بنسخة للفتح السريع وللاطلاع عند انقطاع الإنترنت؛ **الحفظ يحتاج إنترنت**.
  عند «تسجيل الخروج» تُمسح النسخة من الجهاز.
- إذا كان الطبيب يستخدم النسخة السابقة (البيانات على الجهاز فقط)، يظهر له بعد أول دخول عرض لنقل بياناته إلى حسابه.
- النسخة الاحتياطية من لوحة المزود («نسخة») تُستعاد من الإعدادات ← البيانات داخل البرنامج.
